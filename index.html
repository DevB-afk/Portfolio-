Featured project

🏠 Homelab & DevFlix media server

A five-machine home infrastructure built from repurposed desktops and Raspberry Pis. It digitizes my Blu-ray, DVD, and digital movie collection and streams it anywhere through DevFlix, a self-hosted Jellyfin server.

Proxmox VEOpenMediaVaultJellyfin TailscaleRaspberry PiLinuxNetworking

Roadmap

  • Add spare 2 TB and 1 TB drives to the NAS
  • VLANs on the managed switch
  • GPU hardware transcoding for Jellyfin
  • Put the Raspberry Pis to work (monitoring, DNS, backups)
  • Automated backups for Proxmox guests

Storage separate from compute

Media lives on its own NAS, so I can rebuild or snapshot Proxmox guests without ever risking the library.

No open ports

Tailscale gives every node a private name and address from anywhere, with nothing exposed on the router.

Dedicated ripping box

Ripping is slow and disk-heavy, so the ProDesk handles it and the hypervisor stays free for streaming.
